운영자

  1. 서버와 모든 클라이언트에 guild-0.2.0.jar를 넣습니다. server.properties의 spawn-npcs=true, spawn-animals=true(false면 말·가축이 바로 사라집니다).
  2. 길드 앞에서 /guild setspawn, NPC 자리마다 /guild npc guild 등.
  3. 땅 두 모서리에서 /guild plot pos1 · pos2 → /guild plot create house1 house 1500.
  4. 새 NPC: /guild npc auction(경매인) · life(생활 직업) · request(의뢰).
  5. 결투장 가운데에서 /guild arena set, 필드 보스 자리마다 /guild boss setspawn <id>, 숨긴 상자를 바라보고 /guild hidden add small|medium|large.

/guild xp|level <대상> <값>, /guild elite <몹>, /guild boss spawn|setspawn|next <id>, /guild mail hand|money …(점검 보상, 접속 안 한 사람 포함), /guild card|element|scroll <id>, /guild karma <대상> <값>, /guild quest <대상> <id>, /guild daily reset, /guild dungeon reset, /guild hidden list|remove.
